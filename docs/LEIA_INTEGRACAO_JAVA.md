# Teste do EcoLar v2 com Java e Oracle no Windows

Abra o projeto Java e o repositório do front em pastas separadas. O React usa Fetch para falar com o Java. As credenciais do Oracle ficam no processo Java. O Java chama o Flask apenas para gerar previsões e análises.

1. No computador que vai executar o Java, confira o JDK 21 com `java -version`. Extraia o ZIP Java e abra `EcoLar_Java/INICIAR_JAVA_WINDOWS.bat`. Informe a URL JDBC, o usuário e a senha da conexão do grupo. Para um Flask local na porta 5000, aceite o endereço sugerido. Mantenha a janela aberta. Se o Java já estiver em execução nesse PC, use a instância existente.
2. Abra http://localhost:8080/health. O resultado esperado tem `status` igual a `UP` e `banco` igual a `conectado`. Se o endereço não abrir, confira a janela do Java. Se retornar 503, confira a conexão Oracle nesse PC. Abra http://localhost:8080/residencias para confirmar a consulta das tabelas.
3. No Git Bash do repositório React, rode `test -f .env.local || cp .env.example .env.local`. Abra o arquivo no VS Code com `code .env.local` e deixe uma única linha para a base: `VITE_API_BASE_URL=http://localhost:8080`. Preserve outras configurações. Se o Java estiver em outro computador, use uma URL acessível deste navegador e uma origem permitida no CORS do Java. Em produção, configure a URL HTTPS pública da API na Vercel e a origem pública do front no Java.
4. No repositório React, execute `npm ci --include=optional`, `npm run check`, `npm run build` e `npm run dev`. Abra http://localhost:5173/residencias. Reinicie o Vite ao editar o arquivo de ambiente. Se 5173 estiver em uso por outra execução do front, encerre a anterior com Ctrl+C.
5. Confira a lista de residências. Abra uma casa e selecione o intervalo em que há consumos. Os exemplos fornecidos pelo grupo usam outubro de 2026. Confira os totais, as metas e o histórico.
6. Para verificar a gravação, crie uma residência de teste com nome fácil de identificar, anote o ID retornado, registre um consumo em uma data passada e recarregue a página com F5. Confira o mesmo ID, a data e o valor. Em F12 > Network, o cadastro deve retornar 201 e a consulta posterior deve retornar 200. Use essa casa para testar edição e metas. Se optar por limpar o teste, exclua somente os seus registros, começando pelos filhos.
7. Para testar IA, execute também o Flask do grupo no endereço configurado no Java. No painel de uma casa com sete consumos diários consecutivos, selecione o último dia da sequência em “Último dia observado”. Para a carga original da Casa Aurora, experimente 14/10/2026 se os registros de 08 a 14/10 estiverem presentes. Clique uma vez em “Gerar previsão” e uma vez em “Analisar padrão”. Cada ação bem-sucedida grava uma inferência. Confira o resultado, o modelo e os avisos. Um retorno 409 pode indicar uma lacuna nos sete dias.
8. Registre os resultados reais antes de atualizar as evidências da entrega. O teste local confirma o ambiente do grupo. Repita a consulta e a gravação pela URL pública do front após configurar a API remota e o CORS.

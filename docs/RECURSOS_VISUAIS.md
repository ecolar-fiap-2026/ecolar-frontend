# Recursos visuais do EcoLar v2

`public/images/casa-ecolar.webp`: ilustração original gerada com o recurso integrado de geração de imagens do ChatGPT, em 15/11/2026, para este projeto. A referência visual foi fornecida pelo grupo. A imagem não é um template de site: navegação, componentes, tipografia, layout e interações são implementados em React e Tailwind.

A imagem tem transparência, mede 1448 × 1086 px e foi convertida para WebP com aproximadamente 318 KB para distribuição no site. O arquivo faz parte do projeto e não depende de um endereço externo. O alt descreve a cena; largura e altura estão declaradas para reservar espaço durante o carregamento.

Os ícones são da biblioteca Lucide já usada no projeto. Os símbolos ao lado dos ODS são ícones ilustrativos, não selos oficiais de certificação ou parceria. O projeto não afirma apoio institucional da ONU.
